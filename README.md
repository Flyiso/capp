Android application that use a live camera feed to estimate dominant colors an suggests matching colors based on color theory.

Color modes:
* RGB
* HEX
* HSL
* CMY
* NCS (This also displays the best matching NCS color instead of the default calculated ones)

Camera and video flow:
* Front Camera
* Back Camera
* Pause/unpause (by clicking/expanding the palettes)
* Adjust capture region by moving and re-shaping the capture rectangle

Available Palettes:
* Complementary
* Analogous
* Split Complementary
* Triadic
* Tetratic
* Square Tetratic
* Monochromatic
